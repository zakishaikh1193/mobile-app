## 🎯 How to Use the AR Camera

### Step 1: Access AR Zone
1. Navigate to Child Dashboard
2. Click on "AR Magic Zone" section
3. Or go directly to `/ar-zone/:childId`

### Step 2: Start Camera
1. Click "Start AR Camera" button
2. Allow camera permissions when prompted
3. Wait for camera initialization (loading spinner)
4. Camera will start with scanning indicator

### Step 3: Object Detection
1. Point camera at pictures in your book
2. Watch for the scanning animation
3. Objects will be detected automatically
4. 3D models will appear with animations

### Step 4: Interact with Objects
1. **Rotate**: Use rotation buttons to turn the model
2. **Scale**: Use zoom buttons to resize
3. **Reset**: Click reset to return to original view
4. **Sound**: Click play button to hear object sounds
5. **Facts**: Click on fact buttons to hear educational content

### Step 5: Clear and Continue
1. Click "Clear Object" to remove current detection
2. Continue scanning for more objects
3. Use "Stop Camera" when finished

## 🐛 Troubleshooting

### Camera Issues
- **Permission Denied**: Check browser settings and allow camera access
- **No Camera**: Ensure device has camera and it's not in use by other apps
- **Poor Quality**: Check lighting and camera cleanliness

### Detection Problems
- **No Objects Detected**: Try pointing at different objects or adjusting lighting
- **Slow Detection**: Be patient, detection takes 2-6 seconds
- **False Detections**: This is normal for demo purposes

### Performance Issues
- **Slow Animations**: Close other apps to free up memory
- **Audio Problems**: Check device volume and audio permissions
- **Freezing**: Refresh the page if needed
